# Priyanshu Jain

Electrical and Electronics Engineering student at ABV-IIITM Gwalior, focused on digital design, computer architecture, and memory hardware. I like taking designs from RTL through verification to ASIC/FPGA implementation, and measuring the trade-offs.

## What I work on

- **RTL design** in Verilog/SystemVerilog: pipelined datapaths, FSMs, cache coherence
- **Verification:** self-checking testbenches, SVA, cocotb
- **Implementation and analysis:** Yosys, OpenSTA, SkyWater 130 nm, Vivado
- **Circuits:** CMOS characterization with HSPICE; in-memory computing research in Cadence and LTspice
